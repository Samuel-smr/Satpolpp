PENJELASAN CLASS DIAGRAM SIPRAJA
Pembaruan: 21 September 2026

1. LAPIS AKTOR DAN AKSES

Pelapor
- Aktor tamu, bukan model akun.
- Memakai GuestAccess untuk kepemilikan laporan di browser.
- Membuat Report, melihat status miliknya, memberi feedback, dan memakai Asisten AI.

Admin dan Super Admin
- Keduanya direpresentasikan oleh model User dengan enum UserRole.
- Middleware role membatasi route dan tindakan.
- Admin menangani Report; Super Admin berfokus pada dashboard, user, officer, kegiatan, dan monitoring.

2. KELAS LAPORAN

PelaporController
- Menampilkan form, menyimpan laporan tunggal bertipe lapor, menampilkan status, dan menyimpan feedback.

AiAssistantController + AskAiAssistantRequest + GeminiAssistant
- Memvalidasi pesan/riwayat, meneruskan percakapan ke Gemini dari server, dan mengembalikan JSON aman.
- API key tidak pernah dikirim ke browser.

AdminReportController
- Membuat laporan yang dicatat Admin dan melakukan soft delete.

ReportStatusController
- Memajukan status laporan sesuai urutan yang diizinkan.

CompleteReportController
- Menyelesaikan laporan in_progress dan membuat Activity eksternal terkait.

Report
- Model inti laporan; mempunyai GuestAccess/User opsional, riwayat status, lampiran, dan Activity opsional.
- reporter_nik nullable, terenkripsi bila terisi, dan tidak digunakan pada form warga.

3. KELAS KEGIATAN

ActivityController
- CRUD kegiatan internal untuk Admin/Super Admin.

ActivityEvaluationController
- Menambah, memperbarui, dan menghapus data evaluasi pada Activity.

Activity
- Mempunyai template opsional, pembuat, evaluator opsional, petugas, temuan, dan lampiran.
- Activity eksternal mempunyai satu Report; Activity internal tidak mempunyai Report.

Officer
- Petugas yang dapat ditugaskan ke banyak Activity.
- Tidak mempunyai relasi OrganizationalUnit atau OperationalZone.

4. KELAS ADMINISTRASI

ArchiveController mengelola Archive dan ArchiveFile.
OfficerController mengelola Officer.
SuperAdminController mengelola dashboard, akun Admin, monitoring, dan asset alerts.
AdminController menyediakan dashboard/list/detail laporan, kegiatan, dan feedback.
ProfileController mengelola profil akun sendiri.
NotificationController mengelola notifikasi database.
GlobalSearchController menyediakan pencarian sesuai role.
