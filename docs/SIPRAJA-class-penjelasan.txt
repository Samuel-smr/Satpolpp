PANDUAN HALAMAN DRAW.IO
File SIPRAJA-class.drawio memiliki sembilan tab:
01 - Peta model domain: model inti, relasi, dan multiplicity ringkas.
02 - Model laporan: atribut/method User, GuestAccess, Report,
     ReportStatusHistory, Attachment, dan enum ReportStatus.
03 - Model kegiatan: atribut/method Activity, ActivityTemplate,
     ActivityPersonnel, ActivityFinding, Employee, dan enum kegiatan/temuan.
04 - Model administrasi: User, Archive, ArchiveFile, AuditLog,
     DatabaseNotification Laravel, NewReportNotification, dan role akun.
05 - Controller pelaporan: autentikasi, pelaporan publik/internal, AI,
     penugasan, status, penyelesaian, serta akses bukti laporan.
06 - Controller operasional: seluruh controller kegiatan, evaluasi, arsip,
     akun, profil, notifikasi, pencarian, pegawai, tahun, dan lampiran kegiatan.
07 - Service tahun dan akses: OtpService, WhatsAppService, GeminiAssistant,
     EprofilService, DataYear, middleware, provider/gate, serta sistem luar.
08 - Validasi Form Request: seluruh kelas request dan pewarisan khusus
     UpdateInternalActivityRequest terhadap StoreInternalActivityRequest.
09 - Seluruh tabel dan relasi: satu kanvas berisi seluruh 21 tabel database
     SIPRAJA, seluruh 182 kolomnya, tipe fisik, PK/FK/UQ/indeks, nullability,
     default, dan relasi lengkap, termasuk tabel pendukung serta migrations.

Tab 09 menggunakan metadata database lokal polpp (MySQL) yang dibaca pada
28 Oktober 2026, bukan hanya daftar atribut model. Seluruh 15 foreign key fisik
digambar dengan garis utuh dan kardinalitas. Sepuluh referensi logis, morph,
konfigurasi, atau API memakai garis putus dan tidak dianggap sebagai FK fisik.
API e-Profil ditampilkan sebagai sistem luar dan tidak dihitung sebagai tabel.
Tabel tanpa FK tetap ditampilkan tanpa dibuatkan relasi database tambahan.
Gunakan zoom/pan pada tab 09 karena seluruh tabel ditempatkan dalam satu kanvas.

Pilih tab di bagian bawah editor Draw.io. class simple.drawio merupakan
ringkasan model; gunakan SIPRAJA-class.drawio untuk seluruh detail.
Setiap atribut, method, dan label relasi dapat diedit sebagai elemen Draw.io.

NOTASI
- Atribut model adalah atribut dinamis Eloquent, bukan deklarasi properti PHP
  public yang ditulis satu per satu. Tipe mengikuti casts bila tersedia.
- + public, # protected, - private. (...) menyingkat daftar parameter method.
- Garis utuh menunjukkan asosiasi; angka menunjukkan multiplicity data.
- Panah putus menunjukkan dependency. Relasi morph diberi label secara khusus.
- Kelas framework dan sistem luar diberi stereotype agar tidak disangka kelas
  App atau tabel lokal. Pewarisan dasar yang berulang diterangkan pada catatan.
- Halaman ringkasan memilih atribut/method inti; halaman model detail memuat
  seluruh atribut dari skema. Tidak semua enum pendukung digambar ulang pada
  setiap halaman; tipe enum tetap tertulis pada atribut yang menggunakannya.
- Tab 09 merupakan tampilan struktur tabel pada berkas class diagram; tipe
  atributnya adalah tipe database, bukan visibility atau tipe properti PHP.
  PK = primary key, FK = foreign key, UQ = unik, IDX = indeks, NN = NOT NULL,
  NULL = boleh kosong, AI = auto increment. Default dan indeks gabungan juga
  ditampilkan. Tabel framework bukan kelas model aplikasi baru.

1. AKSES DAN TAHUN DATA
User mewakili akun Admin/Super Admin dengan role dan status. Gate access-admin,
access-super-admin, serta manage-report membatasi tindakan. Admin penanggung
jawab aktif saja yang dapat mengubah laporan. Semua Admin dapat membaca laporan
tahun terpilih; Super Admin mengatur penugasan tanpa memproses status.
DataYear membaca pilihan tahun dari sesi dan membatasi query tanggal.
DataYearController menyimpan pilihan; EnsureSelectedDataYear memeriksa objek
Report/Activity/Archive pada route agar sesuai tahun. Tidak ada model Tahun.

2. LAPORAN DAN KOMUNIKASI
PelaporController: OTP, laporan warga, token browser, status, dan feedback.
StoreGuestReportRequest: WhatsApp terverifikasi, deskripsi, lokasi teks,
foto opsional, dan persetujuan. Form publik tidak meminta nama/NIK/koordinat.
OtpService: kode lima menit, verifikasi 15 menit pada sesi, jeda kirim 60 detik.
WhatsAppService: OTP, konfirmasi laporan publik, pemberitahuan Admin aktif,
status/penolakan, dan hasil selesai dengan tautan SKM.
AiAssistantController + AskAiAssistantRequest + GeminiAssistant: pesan maksimal
600 karakter, riwayat server delapan pesan/30 menit, pembatasan penggunaan,
API key server, dan respons aman. Payload history dari browser dilarang.
AdminReportController: laporan kanal lain dan soft delete terotorisasi.
ReportAssignmentController + AssignReportRequest: Super Admin menetapkan Admin
aktif atau mengosongkan penugasan, dengan transaksi dan audit.
ReportStatusController: transisi satu tahap dan penolakan hanya saat verifying.
CompleteReportController: transaksi penyelesaian in_progress dan satu kegiatan
eksternal, NIP personel, temuan, bukti, riwayat, dan audit.
Report: guestAccess(), createdByUser(), assignedAdmin(), statusHistories(),
attachments(), activity(). Kolom reporter_nik sudah dihapus.

3. KEGIATAN DAN PERSONEL
ActivityController mengelola kegiatan internal Admin/Super Admin.
ActivityEvaluationController mengelola evaluasi Admin; kegiatan eksternal
memerlukan kewenangan atas laporan terkait.
Activity mempunyai template, pembuat/evaluator, report opsional, personnel(),
findings(), dan attachments(). Atribut officers merupakan accessor hasil
resolusi e-Profil, bukan relasi belongsToMany ke model Officer lokal.
ActivityPersonnel menyimpan employee_nip, peran, dan catatan pada kegiatan.
EprofilService mengambil direktori pegawai melalui API, menyelesaikan referensi
NIP menjadi Employee, dan menyediakan peringatan jika API gagal. Employee adalah
objek nilai readonly berisi employee_number, name, position; bukan model Eloquent.
NIP unik per kegiatan, tanpa FK ke tabel pegawai lokal. Nama/jabatan tidak disalin
ke master lokal. Personel yang tidak tersedia ditampilkan dengan label pengganti.

4. ADMINISTRASI DAN EKSPOR
AdminController menyediakan dashboard, daftar/detail laporan, kegiatan,
dataset ekspor, dan feedback sesuai tahun data.
SuperAdminController: dashboard/peta, akun Admin, dan monitoring audit.
OfficerController hanya menampilkan direktori baca-saja melalui EprofilService.
ArchiveController mengelola Archive/ArchiveFile, maksimal lima file per arsip.
ProfileController mendukung identitas, nomor WhatsApp, dan password sendiri.
NotificationController mengelola notifikasi database per akun/tahun.
GlobalSearchController mencari laporan/kegiatan sesuai role dan tahun.
Ekspor Excel/PDF/Word dilakukan pada halaman kegiatan memakai dataset server
dan route lampiran terotorisasi; bukan kelas model ekspor baru.

NewReportNotification adalah kelas notifikasi aplikasi dengan channel database.
DatabaseNotification berasal dari Laravel dan diakses melalui trait Notifiable
pada User, bukan model Notification yang ditambahkan pada app/Models.
AuditLog tidak mempunyai subject(): MorphTo; subject_type/subject_id merupakan
referensi logis. Pencatatan dipanggil controller untuk aksi yang telah dipasangi
audit, belum mencakup pembuatan laporan, login/logout, atau CRUD akun.

5. RELASI UTAMA
GuestAccess 1:N Report; User 1:N Report sebagai pembuat atau penanggung jawab;
Report 1:N ReportStatusHistory; Report 1:0..1 Activity;
Activity 1:N ActivityPersonnel dan ActivityFinding;
Report/Activity 1:N Attachment secara polimorfik;
Archive 1:N ArchiveFile. Tabel/method historis tidak berarti fitur masih aktif.
Officer, activity_officer, OrganizationalUnit, OperationalZone, dan Asset tidak
lagi menjadi model/tabel aktif. Diagram menampilkan e-Profil sebagai dependensi luar.
