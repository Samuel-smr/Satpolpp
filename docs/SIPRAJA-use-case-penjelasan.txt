PENJELASAN USE CASE SIPRAJA
Pembaruan: 21 September 2026

AKTOR: PELAPOR

P01 — Membuat laporan
Prasyarat : Tidak perlu login.
Alur      : Buka Lapor, isi telepon/nama opsional/deskripsi/lokasi/foto, lalu kirim.
Aturan    : Hanya satu jenis lapor; NIK tidak diminta.
Hasil     : Report berstatus submitted, kode laporan, guest token, riwayat awal, notifikasi Admin.

P02 — Berkonsultasi dengan Asisten AI
Prasyarat : Halaman Lapor terbuka.
Alur      : Kirim pertanyaan atau detail kejadian secara bertahap; minta draf bila informasi cukup.
Aturan    : Jangan kirim data sensitif; rate limit, timeout, dan validasi berlaku.
Hasil     : Jawaban panduan/draf atau pesan aman bila provider tidak tersedia.

P03 — Melihat status laporan sendiri
Prasyarat : Laporan terikat pada guest token browser.
Alur      : Buka Status dan pilih/masukkan kode yang dimiliki.
Hasil     : Status, riwayat, dan informasi penanganan yang diizinkan tampil.

P04 — Memberikan feedback
Prasyarat : Laporan selesai dan belum diberi feedback.
Alur      : Isi rating dan komentar opsional lalu kirim.
Hasil     : Feedback tersimpan satu kali.

AKTOR: ADMIN

A01 — Login dan mengelola profil
Hasil     : Sesi role Admin aktif; akun diblokir ditolak.

A02 — Melihat dan mencari laporan
Alur      : Gunakan daftar, filter, pencarian, dan detail.
Hasil     : Laporan aktif serta bukti yang diizinkan terlihat.

A03 — Mencatat laporan kanal lain
Alur      : Isi sumber online/offline, kontak, deskripsi, lokasi, dan bukti.
Aturan    : Jenis selalu lapor; NIK nullable/tidak wajib.

A04 — Memajukan status
Alur      : submitted → received → verifying → in_progress.
Aturan    : Satu tahap, status awal diverifikasi, riwayat dan audit dicatat.

A05 — Menyelesaikan laporan
Prasyarat : Status in_progress.
Alur      : Isi kegiatan penanganan, petugas, hasil, lokasi, dan bukti.
Hasil     : Activity eksternal terbentuk dan Report menjadi completed.

A06 — Mengelola kegiatan internal
Alur      : Tambah, lihat, edit, soft delete, petugas, temuan, dan dokumentasi.

A07 — Mengelola evaluasi dan arsip
Hasil     : Data operasional tersimpan dan tindakan penting diaudit.

A08 — Melihat feedback dan notifikasi
Hasil     : Admin mengetahui laporan baru serta penilaian layanan.

AKTOR: SUPER ADMIN

S01 — Melihat dashboard dan peta persebaran
Alur      : Buka dashboard; statistik, grafik, dan peta tampil terpadu.
Aturan    : Tidak ada menu Peta terpisah.

S02 — Melihat detail laporan
Aturan    : Baca-saja; Super Admin tidak memajukan atau menyelesaikan laporan.

S03 — Mengelola akun Admin
Alur      : Tambah, edit, blokir/aktifkan, atau hapus akun selain akun sendiri sesuai validasi.

S04 — Mengelola petugas
Alur      : Tambah/edit data petugas, ubah status, atau hapus.
Aturan    : Tidak ada pilihan unit organisasi atau zona operasional.

S05 — Mengelola kegiatan internal
Alur      : Sama seperti akses kegiatan internal yang diberikan kepada Admin.

S06 — Memantau audit
Alur      : Buka Monitoring dan tinjau aktivitas terbaru serta tren.

USE CASE YANG DIHAPUS

- Memilih Lapor Darurat.
- Memilih Informasi & Pengaduan.
- Memasukkan NIK pada laporan warga.
- Membuka menu Peta terpisah.
- CRUD unit organisasi.
- CRUD zona operasional.
- CRUD aset serta peringatan pajak/servis kendaraan.
